# Smart Study Planner

A web-based study planner designed to help students manage:
- assignments
- exams
- study schedules
- deadlines
- productivity tracking

## Features
- User authentication
- Task management
- Calendar integration
- Dashboard analytics
- Notifications
- CSV import/export
- Study timetable generation

## Technologies Used
- HTML
- CSS
- JavaScript
- FullCalendar
- Chart.js
- LocalStorage
